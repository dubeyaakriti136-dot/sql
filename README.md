### **💻 How to Import**

To restore this data into your MySQL server:

1.  **Prerequisites:** Ensure you have a running MySQL server.

2.  **Create Database:** If the database `saitm` does not exist, create it in your MySQL environment:

    ```sql
    CREATE DATABASE saitm;
    ```

3.  **Import Data:** Use the `mysql` command-line client to import the files:

    ```bash
    mysql -u [your_username] -p saitm < saitm_groups_studentds.sql
    mysql -u [your_username] -p saitm < saitm_dep1.sql
    ```

    (You will be prompted to enter your MySQL password.)

After importing, the tables `groups_studentds` and `dep1` will be available in the `saitm` database.
